# Amaura Company OS v3.6.0 — Free-First Operating Integrations

Version 3.6.0 adds the practical human-reviewed operating layer required for a founder-controlled AI workforce without requiring paid APIs.

## Added

- Bounded public-business discovery through DuckDuckGo search and robots-aware company website enrichment.
- Evidence-bound lead creation, contact enrichment, deterministic scoring and CRM persistence.
- Gmail inbox ingestion with OAuth renewal, MIME parsing, idempotent storage and reply classification.
- Signed Meta webhook ingestion for WhatsApp, Facebook Messenger and Instagram business messages.
- Immediate opt-out enforcement and approval-queued reply drafting.
- Founder-reviewed assisted handoffs for LinkedIn, Instagram, Facebook and WhatsApp. The system prepares the exact packet and never clicks Send.
- Durable founder-approved action queue for Calendar, Drive, GitHub, analytics, social publishing, Telegram and Nexus.
- Provider health state, circuit breakers, retry/reconciliation binding and signed provider receipts.
- Google Calendar event creation, Drive upload, GitHub issue/workflow actions and PostHog event capture.
- Telegram founder commands and integration-action approval buttons.
- Local HTML invoices and UPI payment requests; consequential payment state remains founder-confirmed.
- Approval-gated Nexus subprocess bridge using argv execution, repository validation, bounded timeouts and result receipts.
- Atomic publication dispatch that produces one outbox record, one event and one audit record across concurrent processes.
- Self-generated qualification evidence bound to test shards, security scan, source gate, Git commit and artifact hashes.

## Explicit safety boundary

Amaura does not implement stealth automation, CAPTCHA bypass, anti-bot evasion or unrestricted mass messaging. Restricted social channels use assisted execution unless an approved official API is configured. First contact, public posting, CI/CD dispatch, client commitments, deployment and money-related state changes remain founder-controlled.
